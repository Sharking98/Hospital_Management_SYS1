# Hospital Patient Management System

## 1. Introduction
The Hospital Patient Management System is a mini project developed using the C programming language. It is designed to manage basic patient information.

## 2. Objectives
- To register patient details.
- To view registered patients.
- To search for patients using Patient ID.
- To update patient information.
- To delete patient records.

## 3. Technologies Used
- Programming Language: C
- Code Editor: Visual Studio Code
- Compiler: GCC (if used)

## 4. Project Modules
1. Main Menu
2. Add Patient
3. View Patients
4. Search Patient
5. Update Patient
6. Delete Patient

## 5. Patient Information
The program manages:
- Patient ID
- Name
- Age
- Gender
- Symptoms

## 6. How to Run
1. Download or clone the repository.
2. Open the project in Visual Studio Code.
3. Compile the C source code using a C compiler.
4. Run the generated program.

## 7. Conclusion
This project demonstrates the use of structures, arrays, functions, loops, and conditional statements in C programming for basic patient record management.
